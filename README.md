## 🚀 Featured Projects

### 🚕 NYC TaxiGuard
**Big Data · Team Leader**

Real-time taxi demand and anomaly detection pipeline. Spark handles batch analysis over ~4 million trips, Kafka + Flink produce real-time demand windows and basic anomaly detection on a simulated stream of ~1,000 trips/minute, and a live Streamlit dashboard shows an interactive taxi-zone map.

`HDFS` `Spark` `Kafka` `Flink` `Streamlit` · [**View Repository →**](https://github.com/joseph-emadd/NYC-Taxi-Big-Data)

---

### ⚽ Football Player & Referee Detection and Tracking
**Computer Vision · Team Leader**

YOLO11n trained for 100 epochs at 640x640 to detect players, goalkeepers and referees (label validation, 80/20 train/validation split). ByteTrack tracks them across match video and generates tracked output videos.

`YOLO11` `ByteTrack` `PyTorch` `OpenCV` · [**View Repository →**](https://github.com/joseph-emadd/Player-And-Refree-Detection)

---

### 🎓 Student Performance Prediction
**Machine Learning · Kaggle**

Compared 16 regression models, from Linear, Ridge and Lasso to XGBoost, LightGBM and CatBoost. Linear Regression scored best (R² = 0.988, MAE = 1.65).

`Scikit-learn` `XGBoost` `LightGBM` `CatBoost` · [**View on Kaggle →**](https://www.kaggle.com/code/josephemadd/student-performance-prediction-regression)
