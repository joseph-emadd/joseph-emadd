## Selected Projects

### NYC TaxiGuard: Real-Time Taxi Demand Analytics
*Team Leader · Big Data*

Spark for batch analysis over ~4 million trips, Kafka and Flink for real-time demand windows and basic anomaly detection, and a live Streamlit dashboard with an interactive taxi-zone map. Streaming was simulated at ~1,000 trips per minute.

**Stack:** HDFS · Spark · Kafka · Flink · Streamlit · [Repository](https://github.com/joseph-emadd/NYC-Taxi-Big-Data)

### Football Player & Referee Detection and Tracking
*Team Leader · Computer Vision*

YOLO11n trained for 100 epochs at 640x640 to detect players, goalkeepers and referees, with label validation and an 80/20 train/validation split. ByteTrack tracks the detected objects across match video and generates tracked output videos.

**Stack:** YOLO11 · ByteTrack · PyTorch · OpenCV · [Repository](https://github.com/joseph-emadd/Player-And-Refree-Detection)

### Student Performance Prediction
*Machine Learning · Kaggle*

Compared 16 regression models, from Linear, Ridge and Lasso to XGBoost, LightGBM and CatBoost. Linear Regression scored best (R² = 0.988, MAE = 1.65).

**Stack:** Python · Scikit-learn · XGBoost · LightGBM · CatBoost · [Notebook](https://www.kaggle.com/code/josephemadd/student-performance-prediction-regression)
